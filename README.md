# Brain.exe — GitHub Organization Profile Package

This package is prepared for a **public GitHub repository named `.github`** under the `Team-Brain-exe` organization.

## Repository layout

- `profile/README.md` — the organization landing-page README. GitHub displays this on the organization overview page.
- `project-readmes/` — seven individual project README drafts that can be linked from the landing page or copied into the corresponding project repositories.

## Publish the organization profile

1. Open the `Team-Brain-exe` GitHub organization.
2. Create a **public** repository named `.github` (if it does not already exist).
3. Upload the contents of this package's root into that repository. Do not create an extra enclosing folder.
4. Commit the files. GitHub should display `profile/README.md` on the organization overview page.

## Before publishing

- Replace the four members' GitHub and LinkedIn placeholders in `profile/README.md`.
- Replace `ADDMORE_TECHNOLOGIES_URL` with the official company website or LinkedIn URL.
- Add the Smart Irrigation repository URL when known.
- Review project descriptions and confirm each repository is public and correctly named.
- Trauma Route is documented as one system with three repositories.
- Orbitveil's repository is under `Orbitveil-SIH`, not `Team-Brain-exe`.

## Individual project documentation

The `project-readmes/` directory contains separate Markdown drafts for all seven projects. Review each and copy it into the matching repository as `README.md` if you want the project repository's front page to use the expanded documentation.
