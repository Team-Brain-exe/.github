# Project-44

### Real-Time Shipping Risk Intelligence

Project-44 is a real-time shipping risk intelligence platform for global trade corridors. It uses machine learning for route-risk scoring, provides disruption alerts, and supports AI-assisted rerouting to help identify and respond to risks affecting shipping routes.

## Capabilities

- Route-risk scoring using machine learning
- Disruption alerts for shipping corridors
- AI-assisted rerouting support
- Interactive map-based frontend

## Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React 19, Vite, TypeScript |
| Mapping | Leaflet, React-Leaflet |
| UI | Tailwind CSS |
| Backend | Python, FastAPI, Uvicorn |
| Data / ORM | SQLAlchemy, Alembic |
| Validation / Configuration | Pydantic, Pydantic Settings, python-dotenv |
| Machine Learning | Scikit-learn, NumPy, Pandas, SciPy, Joblib |
| AI Integration | Groq |
| HTTP / API | Requests, HTTPX |
| Testing | Pytest |

## Architecture

React frontend connected to a Python-based FastAPI and machine-learning backend.
