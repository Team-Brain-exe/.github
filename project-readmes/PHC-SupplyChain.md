# PHC-SupplyChain

### Primary Healthcare Supply-Chain Monitoring

PHC-SupplyChain is a supply-chain management and monitoring platform focused on improving visibility and coordination across primary healthcare supply operations. The application combines an interactive frontend with a Python-based backend and data/ML tooling to support supply-chain analysis and operational decision-making.

## Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React 19, Vite |
| UI | Tailwind CSS |
| Mapping | Leaflet, React-Leaflet |
| Backend | Python, FastAPI, Uvicorn |
| Database / ORM | SQLAlchemy |
| Migrations | Alembic |
| Validation / Configuration | Pydantic, Pydantic Settings, python-dotenv |
| AI / ML | Google Generative AI, Scikit-learn, XGBoost, NumPy, Pandas, SciPy, Joblib |
| Scheduling / Automation | APScheduler |
| Data / Web Processing | BeautifulSoup |
| Testing | Pytest |

## Architecture

React frontend connected to a Python FastAPI backend, with analytics and AI capabilities.
